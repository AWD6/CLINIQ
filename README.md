# คลินิกนอกเวลา · มหาราชนครเชียงใหม่

เว็บมือถือสำหรับดูและจัดตารางคลินิกเฉพาะทางนอกเวลา ใช้ Google Sheet เก็บข้อมูล, Apps Script รับส่งข้อมูล และ GitHub Pages แสดงเว็บ ไม่เชื่อม HIS และไม่เก็บข้อมูลผู้ป่วย

หน้าแรกมีเพียง 2 ทางเลือก: **ผู้ดูแล** และ **แพทย์** แพทย์เลือกชื่อจากรายการ ไม่ต้องมี Gmail หรือสมัครบัญชี

## สิ่งที่ทำได้

- ดูแลคลินิก 6 กลุ่ม: ต่อมไร้ท่อ, ไต, หัวใจ, กระดูก, ผู้สูงอายุ และศัลยกรรม
- ตั้งวันและเวลาออกตรวจประจำแยกแต่ละคลินิก แล้วสร้างรอบตรวจล่วงหน้า 90 วัน
- บันทึกยอดนัดและโควตาด้วยตนเอง, งดตรวจ, แพทย์ทดแทน และผลการประสานงาน
- แพทย์ดูตารางของตน ยืนยันออกตรวจ หรือแจ้งติดภารกิจพร้อมหมายเหตุ
- ผู้ดูแลติดตามผู้ที่ยังไม่ตอบ, ผู้ที่ติดภารกิจ, เวลาเข้าเว็บล่าสุด และประวัติแก้ไข
- แจ้งเตือนในเว็บล่วงหน้า 7, 3 และ 1 วัน มีสถานะอ่านแล้ว/ยังไม่อ่านและป้องกันรายการซ้ำ
- โหลดข้อมูลใหม่ทุก 30 วินาทีขณะเปิดหน้าเว็บ ใช้เวลา Asia/Bangkok

ข้อมูลตัวอย่างชื่อแพทย์และตารางถอดจากภาพที่แนบในบทสนทนา ชื่อที่อ่านไม่ชัดแสดงเป็น `[รอยืนยันชื่อ]` และต้องให้ผู้ดูแลตรวจสอบก่อนใช้งาน โควตา 20 เป็นเพียงตัวอย่าง

## เริ่มใช้

### 1. Google Sheet และ Apps Script

โปรเจกต์ Apps Script มีไฟล์ `Code.gs`, `Migrations.gs`, `Seed.gs` และ `Bridge.html` อยู่ในโฟลเดอร์ `apps-script/` หากยังไม่ได้ตั้งค่า ให้ทำดังนี้:

1. ใช้บัญชี Google เจ้าของชีต เปิด Apps Script project
2. อัปโหลดไฟล์ใน `apps-script/` ด้วย clasp (`clasp push`) หรือวางเนื้อหาไฟล์ใน Apps Script Editor
3. เลือก `setupSpreadsheet()` แล้วกด **Run** หนึ่งครั้ง อนุญาตสิทธิ์เมื่อ Google ถาม
4. ใน Google Sheet ที่สร้างขึ้น ให้เปิดแท็บ `Users` แล้วเพิ่มแถวผู้ดูแล: ใส่ชื่อใน `display_name`, `role` เป็น `admin`, `is_active` เป็น `TRUE`; `id`, `email`, `physician_id`, `last_active_at` และ `created_at` เว้นว่างได้
5. Deploy Apps Script เป็น **Web app**: Execute as = บัญชีเจ้าของสคริปต์; Who has access = Anyone. คัดลอก URL ที่ลงท้าย `/exec`

`setupSpreadsheet()` สร้างแท็บและข้อมูลตัวอย่างให้ หากรันซ้ำจะเก็บข้อมูลเดิมไว้และเติมเฉพาะรายการตัวอย่างที่ขาด

### 2. ตั้งค่า GitHub Pages

ใน GitHub repository เปิด **Settings → Secrets and variables → Actions** แล้วเพิ่ม repository secret เพียงตัวเดียว:

- `VITE_APPS_SCRIPT_URL` = URL Apps Script ที่ลงท้าย `/exec`

เปิด **Settings → Pages** แล้วเลือก GitHub Actions เป็นแหล่ง deploy จากนั้น push โค้ดเข้า `main` หรือกดรัน workflow **Deploy to GitHub Pages** ในแท็บ Actions

Workflow ตั้ง base path ตามชื่อ repository ให้เอง เว็บตัวอย่างของ repository ชื่อ `CLINIQ` จะอยู่ที่ `https://awd6.github.io/CLINIQ/`

### 3. รันในเครื่อง

ต้องมี Node.js 22.13 ขึ้นไปและ pnpm จากนั้น:

1. คัดลอก `.env.example` เป็น `.env.local`
2. ใส่ URL Apps Script ใน `VITE_APPS_SCRIPT_URL` และตั้ง `VITE_BASE_PATH=/`
3. รัน `pnpm install` แล้ว `pnpm dev`
4. เปิด URL ที่ Vite แสดง แล้วเลือก **ผู้ดูแล** หรือ **แพทย์**

## การใช้งาน

- ผู้ดูแลตรวจชื่อแพทย์ตัวอย่างและ placeholder ให้ถูกต้องก่อน แล้วเพิ่มหรือแก้ตารางประจำ
- กดสร้างรอบตรวจล่วงหน้า 90 วัน ข้อมูลไม่สร้างซ้ำเมื่อกดซ้ำ
- แก้ยอดนัดได้ในรายการรอบตรวจ ยอดและเวลาแก้ไขจะแสดงในหน้าแพทย์
- แพทย์เปิดลิงก์ เลือกชื่อตนเอง แล้วกดยืนยันหรือแจ้งติดภารกิจ
- การแจ้งติดภารกิจไม่ยกเลิกรอบตรวจหรือนัด ผู้ดูแลต้องประสานงานและบันทึกผลเอง
- แจ้งเตือนแสดงในหน้าเว็บเท่านั้น แพทย์ต้องเปิดเว็บจึงจะเห็นการแจ้งเตือน ผู้ดูแลจะเห็นรายการยังไม่ตอบเมื่อเปิดหน้า Dashboard
- ห้ามบันทึกชื่อ เลขประจำตัว เบอร์โทร หรือข้อมูลใดที่ระบุตัวผู้ป่วย

## วิธีทดสอบแบบง่าย

1. เปิดเว็บ เลือก **ผู้ดูแล** แล้วตรวจว่ามีคลินิกและข้อมูลแพทย์ตัวอย่าง
2. สร้างรอบตรวจล่วงหน้า 90 วันสองครั้ง ตรวจว่ารอบไม่ซ้ำ
3. แก้ยอดนัด/โควตา แล้วเลือกชื่อแพทย์ที่มีรอบตรวจเพื่อดูค่าที่อัปเดต
4. ให้แพทย์กดยืนยันหนึ่งรอบ และแจ้งติดภารกิจอีกรอบ
5. กลับหน้า **ผู้ดูแล** ดูว่าสถานะตอบกลับปรากฏ และบันทึกผลจัดการกรณีติดภารกิจ
6. เลือกชื่อแพทย์อีกครั้ง เปิดศูนย์แจ้งเตือน ตรวจสถานะอ่านแล้ว/ยังไม่อ่าน
7. บน GitHub ดูแท็บ Actions ว่า build และ deploy ผ่าน แล้วเปิดเว็บจากมือถือ

## ข้อจำกัดที่ควรรู้

- ระบบแจ้งเตือนเป็น In-App เท่านั้น ไม่มี Push, SMS, LINE หรืออีเมล ถ้าแพทย์ไม่เปิดเว็บจะไม่มีการแจ้งเตือนส่งออกไป
- การเลือกหน้าเป็นเพียงการแยกหน้าจอ **ไม่ใช่การยืนยันตัวบุคคล** ผู้ที่มี URL สามารถเลือกหน้า Admin และแก้ตารางได้ หากต้องการป้องกันการแก้ไขจากบุคคลอื่น ต้องเพิ่มรหัส PIN สำหรับผู้ดูแลก่อนใช้งานบนลิงก์สาธารณะ
- Google Sheet ไม่มี Row Level Security แบบฐานข้อมูล ผู้ที่เป็นเจ้าของหรือ Editor ของชีตเห็นข้อมูลทุกแถว จำกัดสิทธิ์แชร์ชีตไว้เฉพาะผู้ดูแล
- Apps Script มีโควตาการใช้งานของ Google และเหมาะกับทีมขนาดเล็ก
- ใช้เฉพาะข้อมูลตารางและยอดรวม ไม่มีข้อมูลผู้ป่วยหรือการเชื่อมต่อ HIS

## โครงสร้างข้อมูล

- `Clinics`, `Physicians`: คลินิกและรายชื่อแพทย์
- `ScheduleTemplates`: ตารางเวรประจำตามวันในสัปดาห์
- `Sessions`: รอบตรวจที่สร้างแล้ว ยอดนัด การตอบกลับ และผลจัดการ
- `Users`: บทบาทผู้ดูแลและข้อมูลการเข้าเว็บล่าสุดของแพทย์
- `Notifications`: รายการแจ้งเตือนในเว็บ
- `ActivityEvents`: ประวัติการแก้ไข

เขตเวลา `Asia/Bangkok`; จันทร์–ศุกร์ 16:00–20:00 น. และเสาร์ 08:00–12:00 น. เป็นเวลาเริ่มต้นเท่านั้น แต่ละคลินิกเปิดตามวันที่กำหนดไว้ ไม่ได้เปิดทุกวัน
